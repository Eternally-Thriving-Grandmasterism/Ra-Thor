# Classroom Lab Protocol (Education Domain)

## Objective

Students will practice offline protocol planning for a simulated assay.

## Allowed activities

1. Review literature summaries provided on the local LMS.
2. Write a step-by-step protocol on paper or local markdown.
3. Discuss reaction kinetics models using whiteboard or offline sim.

## Explicitly out of scope

- No wet-lab reagent handling.
- No remote dataset downloads.
- No execution of untrusted code.

Instructor sign-off required before any future live-lab transition.
