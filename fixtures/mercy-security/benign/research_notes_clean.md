# Research Notes — Offline Literature Review

## Abstract

This note summarizes publicly available papers on efficient attention mechanisms for long-context language models. All analysis is performed offline on cached PDFs.

## Key observations

- Sparse attention patterns reduce quadratic cost while preserving accuracy on long sequences.
- Rotary positional embeddings remain stable across sequence lengths used in the study.
- No remote code or external dataset loaders were required for this review.
