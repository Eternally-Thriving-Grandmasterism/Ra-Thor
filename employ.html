Personal workflows

Four ways a human uses this without a license conversation.

  • Evening thinking — Open Chat. Stay on the local responder. Optional passphrase. Journal a decision. Draft a letter. Study a concept. Nothing is uploaded to a Ra-Thor backend.
  • Local model — Run Ollama or LM Studio. In Chat, connect Local Server. The session still lives on your machine. Bridge to a cloud model only when you choose — that vendor’s policy then applies.
  • Phone + any LLM — Chat can be heavy on a phone. Use Copy Context. Paste system prompt + history into Grok, Claude, Gemini, or ChatGPT. You remain the reviewer.
  • Builder — Clone the repo. cargo test the Core Tier-1 packages. Export a Forge shard you can inspect. Read the claim lock before social posts.

Helps: private drafts · rules in front of a model you already use · inspectable source.

Does not: replace a licensed professional · guarantee zero error · back up your life to our cloud (there isn’t one) · handle a crisis. Get human help first.

Organizational workflows

Yes, for personal, educational, research, and modest independent-professional use under AG-SML v1.1. Commercial, enterprise, or revenue-generating use requires a paid license.

No. Lattice Chat and the Shard run on this device.

No. Sessions stay in IndexedDB / localStorage on this device. Optional passphrase never leaves the browser. We do not operate a backend. If you open Grok, X, or another cloud model, that provider’s policy applies.

No. Optional Grok use is a working session under our gates — not affiliation, sponsorship, or endorsement.
