# Ra-Thor lineage: AlphaProMega → Ra-Thor

Compiled 2026-10-31 from GitHub history (AlphaProMega and Eternally-Thriving-Grandmasterism), rathor.ai, acitygames.com and public X posts. Times are America/Toronto.

Evidence tiers:
- **[Commit evidence]**: a commit in a GitHub repo.
- **[Public web/X]**: a public page or X post.
- **[Owner account]**: the owner's own records, not independently verified.

Quoted text is the project's own self-description. Terms such as AGI, AGi, AGSi and "eternal" are research identity labels, not capability claims (see [`PUBLIC_CLAIM.lock.md`](../PUBLIC_CLAIM.lock.md)).

Private repos are named with dates only and carry no links.

## Concept threads (as the repos tell it)
- **APMCheck / Quad+Check** → QSA-AGi validation (simulated) → ESA fusion → Ra-Thor Mercy-Checks / FENCA.
- **Anti-hallucination**: the APM-v3 "Classic Core" layer → mercy-gated checks and claim discipline in Ra-Thor.
- **QSA-AGi → ESA → ESAO**: 12-layer sentinel → fused oracle → "Oneness" framing.
- **TOLC / Grandmasterism / Mercy**: human-practice repos from Dec 2025 that became Ra-Thor's core vocabulary in 2026.
- **PATSAGi**: council repos from Jan 2026; no single defining origin doc.
