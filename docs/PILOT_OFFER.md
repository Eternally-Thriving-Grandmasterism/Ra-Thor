## Purpose

Convert serious interest into a **paid, scoped pilot** that proves value quickly — then convert successful pilots into full commercial licenses.

This is the primary high-ticket path for organizations that need to see Ra-Thor work on their problem before committing to a broader license.

---

## What the Pilot Delivers

A fixed-scope engagement (typically **2–6 weeks**) that includes:

1. **Scope lock** — one primary use case (examples below)
2. **Integration or evaluation** of the relevant Ra-Thor surfaces
3. **Demonstration** against the client’s real or representative data / scenarios
4. **Written report** — findings, limits, recommended production path
5. **Conversion path** — clear commercial license terms if the pilot succeeds

Pilot fees are structured so that a successful conversion can credit part or all of the pilot fee toward the commercial license (default for control-layer / Core Lattice pilots: **100% of the pilot fee** if converted within 90 days).
