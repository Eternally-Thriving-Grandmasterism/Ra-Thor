## 2. Dual-gate merge protocol

Every change that touches living product (`Ra-Thor` main, Powrush dual-repo contracts, license/contact surfaces):

### Gate A — PATSAGi valence (required)

Agent or human must affirm, in the PR / commit message or review note:

1. **Truth** — no invented metrics, labels, flight numbers, or affiliations  
2. **Order** — Tier Map respected; focused tests preferred  
3. **Compassion / Zero-Harm** — no dual-use productization; no client legal advice as final  
4. **Abundance** — no scarcity dark patterns in Powrush paths  
5. **Service** — change serves lattice health or clear organ mission  
6. **HOLD doors** — not claiming completion of partner/label/legal work that did not happen  

If any fails → **HOLD** · do not merge.

### Gate B — Steward operator (required for irreversible)

Human steward (or future named co-steward under written onboarding) must:

- Hold secrets and org admin  
- Approve merge to `main` **or** explicitly delegate a **narrow** bot path that still cannot: force-push, secret write, billing, domain, client systems  
- Remain corrigible: can freeze all agents

**Default day-one:** agents open PRs or propose diffs; **steward merges** after Gate A checklist.
