## What’s New in v14.17.0

### 1. Full Markdown + Code Block Rendering
- Headings, bold, italic, lists, links
- Fenced code blocks with language labels
- Inline code
- Clean, readable dark-theme styling

### 2. Session Search
- Instant search across messages in the current session
- Jump to matching content
- Lightweight and fully local

### 3. Lightweight Document Context Injection
- Upload `.txt`, `.md`, `.json`, `.csv` files
- Content is injected into conversation context
- Automatically included in Local Backend / WebLLM calls
- Private, on-device only

### 4. Optional Passphrase Encryption
- AES-GCM encryption of the entire session store via Web Crypto API
- Passphrase-derived key (PBKDF2)
- Off by default — one-click enable
- True privacy maximalist option

### 5. History Summarisation for Long Sessions
- Automatic context management before generative calls
- Keeps Local Backend and WebLLM within practical windows
- Transparent to the user
