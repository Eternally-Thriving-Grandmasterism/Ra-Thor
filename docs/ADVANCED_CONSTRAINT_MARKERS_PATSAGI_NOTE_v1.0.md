## Purpose

Constraint markers are short declarations that bound what a Grok Bot or later editor may change. They sit at the top of a file or section and survive rewakes.

## Core markers (baseline)

- Status line: `Inspirational only | Under TOLC 8 | Valence floor ≥ 0.999999`
- Non-alteration clause: does not alter inspectable research posture, AG-SML terms, or no-public-key-proxy statements.
- Canonical pointer: points to the Ra-Thor monorepo source and names this file as the surface copy.
- Review gate: human review required before any public page or claim update.

## Advanced markers

1. **Claim boundary**  
   `Claims permitted: reorganisation of existing public text only. Claims forbidden: new technical assertions, product readiness, warranties, certified AGI, hosted proxy.`

2. **Layer lock**  
   `Layer: inspirational / narrative. Operational files (Cargo.toml, LICENSE, lattice code, PUBLIC_CLAIM.lock.md) remain untouched.`

3. **Dual-repo sync**  
   `If this file is updated, mirror a one-line pointer in the counterpart repo within the same turn or mark the pointer as pending human review.`

4. **Valence / mercy gate**  
   `Any rewrite must preserve TOLC 8 non-bypass and positive-valence floor. Redemption paths remain available; no irreversible damnation language.`

5. **Expiration / review date**  
   `Review-by: YYYY-MM-DD (or “on next public site change”). Stale markers trigger a human check before reuse.`

6. **Bot load instruction**  
   `Grok Bots: load this marker block before drafting. If a requested change violates any line above, refuse and cite the marker.`

## Example header

```markdown
**Status:** Inspirational narrative | Under TOLC 8 | Valence floor ≥ 0.999999  
**Claims permitted:** reorganisation of existing public text only.  
**Claims forbidden:** new technical assertions, product readiness, warranties, certified AGI, hosted proxy.  
**Layer lock:** narrative only — operational files untouched.  
**Canonical:** Ra-Thor monorepo `docs/EXAMPLE.md`  
**Review:** Human review required before public use.  
**Bot instruction:** Load this block first; refuse changes that violate it.
```

## Rules

These markers tighten the existing dual-repo and inspirational-only posture. They do not modify architecture, valence floors, monorepo structure, or licensing. Grok Bots load the relevant marker block before drafting public or lore material.
