## 1. Law (non-bypassable)

| Rule | Meaning |
| --- | --- |
| **Truth** | No fabricated data, citations, or “we proved X” without artifact |
| **Order** | Ranked portfolio · one active program at a time unless steward opens parallel |
| **Compassion** | No dual-use weaponization of discovery paths |
| **Service** | Prefer problems that reduce harm or increase verifiable thriving |
| **Standard macro** | Reproduce baselines before claiming novelty |
| **Proof > surmise** | Surmise may open a program; only proof closes a discovery claim |

**Definition — Discovery (lattice grade):**  
A result is a *discovery* only if it is (a) non-obvious relative to stated prior art, (b) reproducible from released artifacts, (c) passes a pre-registered success criterion, (d) explicitly lists failure modes.

**Definition — Surmise:**  
A ranked, falsifiable hypothesis with a test plan. Surmise is allowed. Surmise labeled as fact is forbidden.

---

## 2. Proof ladder (what counts)

| Tier | Artifact |
| --- | --- |
| **P0** | Hypothesis + prior-art note + falsifier |
| **P1** | Open data or synthetic baseline + code |
| **P2** | Independent reproduction path (second machine / second operator instructions) |
| **P3** | Quantitative criterion met (pre-registered) |
| **P4** | External critique invited (public preprint or equivalent) |

Claims of “unknown physics” require **≥ P3** in physical/empirical domains, or formal proof artifact in pure math/CS domains.

Software benchmarks (e.g. S-1 micro-moments) are **empirical CS**, not fundamental physics — still held to P1–P3.

---

## 3. How R&D is conducted maximally *without lying*

1. **Survey** what is known (primary literature, not YouTube).  
2. **Gap** — one sentence unknown.  
3. **Surmise** — mechanism sketch + why it could be wrong.  
4. **Minimal experiment** — cheapest test that could kill the surmise.  
5. **Execute** in-repo (sim, formal proof, label pipeline) or HOLD for lab/partner.  
6. **Publish** negative results with same dignity as positive.  

Cursor/agents: Band A for literature tables and harnesses; Band B for new experimental code; Band C for any “physics proven” announcement without P3.
